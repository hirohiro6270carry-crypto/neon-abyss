Ver.2.5.0 — TACTICAL ARSENAL
- 位相アンカー: 通常敵と位置交換、2x2ボスは側面へ転位
- 重力パルス: 通常敵を最大3マス押し出す、壁に当たればスタン/5ダメージ、ボスには1行動停止と予告解除
- 時間凍結チップ: 4マス以内の通常敵2行動・ボス1行動停止、攻撃予告解除
- 光学迷彩: 5ターンの間遠距離の通常敵から狙われなくなる。隣接とボスは対象外
- ハッキングチップ: 通常敵1体を3行動仲間化して他の敵と交戦。ボスは対象外
- 緊急転送装置: ランダムな空き床へ転送、ボス範囲予告の外を優先
- 1フロアにつき1個の戦術道具が出現。初期バッグに位相アンカーと重力パルスを追加。ボス前にも重力パルス支給。
- ターゲット選択をキャンセルした場合は消費・ターン進行なし。
- 既存セーブの読み込み方式は変更なし。セーブはブラウザのURL（オリジン）別に保持されます。
- GitHub Pages向け相対パス維持。オンライン更新後、オフラインキャッシュはv250に更新されます。


Ver.2.6.0 — LIVING LABYRINTH (特殊地形とダンジョンギミック)
・2階以降の通常フロアに搬送床（矢印）、3階以降に跳躍床（⇧）、4階以降に1度きりの防護床（＋）、5階以降に対になった転送床（◎）が出現。
・3階以降に亀裂壁（ひび割れた壁）が出現。亀裂壁に向いて通常攻撃で破壊でき、重力パルスで敵を壁に押し当てた場合にも破壊する。
・特殊地形は通常の通路を塞がない。ボス専用アリーナは従来のギミックを維持する。
・既存セーブ互換：新しい階に入った時点でギミックを生成。探索途中の階の構造は変更しない。
・iPhone上では未検証。アップデート前にセーブデータをエクスポートしてください。
